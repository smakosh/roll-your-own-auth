## CLI

```sh copy
npx ryo-auth@latest add jwt-nextjs-client
```

This copies every file below into your project (under `src/`), shadcn style — then prints the exact dependency install command for your package manager. See all available components with `npx ryo-auth@latest list`.

The client stores the access token in memory (module-level variable), sends it as a `Bearer` header, and auto-refreshes on 401 by calling `/auth/refresh` with `credentials: "include"` to pick up the httpOnly refresh cookie. Server actions wrap signup, login, logout and me.
