### Install dependencies

```sh npm2yarn copy
npm i express dotenv cors passport passport-github2 jsonwebtoken @prisma/client cookie-parser
```

```sh npm2yarn copy
npm i -D prisma @types/express @types/cors @types/passport @types/passport-github2
```

### OAuth flow

1. Client visits `GET /auth/github` — Passport redirects to GitHub.
2. GitHub redirects back to `GET /auth/github/callback`.
3. Handler finds/creates user by `githubId`, generates JWT access + refresh tokens.
4. Sets refresh token as httpOnly cookie, redirects to frontend with access token in URL query.
5. Frontend stores access token in memory.

### Environment variables

```
GITHUB_CLIENT_ID=your_client_id
GITHUB_CLIENT_SECRET=your_client_secret
GITHUB_CALLBACK_URL=http://localhost:4000/auth/github/callback
JWT_SECRET=your_jwt_secret
JWT_REFRESH_SECRET=your_refresh_secret
CORS_ORIGIN=http://localhost:3000
FRONTEND_URL=http://localhost:3000
```
